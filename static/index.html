Pilih dari menu suara Mac

Buka Control Center → Sound di MacBook, lalu pilih Homelab Sony.

AirPlay praktis untuk musik. Pause dan resume tertunda sekitar 2 detik karena sifat AirPlay; untuk video, coba Bluetooth.

◉

Sambungkan lewat Bluetooth biasa

Pasangkan Mac, HP, atau PC ke Homelab Audio seperti ke speaker Bluetooth, lalu pilih sebagai output suara. Tidak perlu aplikasi tambahan.

Belum ada perangkat yang dipasangkan.

Tidak ada jeda 2 detik seperti AirPlay, tetapi audio melewati dua lompatan Bluetooth (perangkat → hub → Sony) sehingga ada tambahan delay. Sinkronisasi video bergantung pada pemutar.

Putar lewat Wi-Fi dengan DLNA

Di pemutar yang mendukung DLNA atau fitur cast bawaan HP, pilih Homelab Audio sebagai perangkat pemutar. Tidak perlu memasangkan.

DLNA memutar berkas atau tautan media (musik lokal, Jellyfin, VLC), bukan seluruh suara perangkat. YouTube dan Spotify tidak cast lewat DLNA; untuk itu pakai Bluetooth.

Hubungkan perangkatmu

Satu sumber diputar pada satu waktu
MacBook

Unduh WFAS Desktop sesuai arsitektur Mac. Pilih Send / Server → Unicast → WFAS native, lalu mulai. Izinkan perekaman layar/audio ketika macOS memintanya. Pilih Mac di daftar pengirim pada dashboard ini. Alternatif tanpa aplikasi pengirim: pilih sumber AirPlay di atas.

CachyOS

Unduh WFAS Linux x86_64. Jalankan mode Send / Server → Unicast → WFAS native. WFAS membuat keluaran audio virtual; pilih keluaran tersebut pada pengaturan suara atau arahkan aplikasi yang ingin didengar ke sana.

Windows

Unduh WFAS Windows x86_64. Pilih Send / Server → Unicast → WFAS native, lalu mulai. Izinkan WFAS pada Windows Firewall untuk jaringan pribadi. Pilih komputer Windows di dashboard ini.

Android

Pasang WFAS Android, pilih mode pengirim dan sumber Internal audio. Izinkan capture audio yang diminta Android, mulai, lalu pilih HP pada dashboard. Capture audio aplikasi memerlukan Android 10+; aplikasi tertentu bisa memblokirnya. Audio panggilan tidak dijamin ikut tertangkap.

Semua perangkat berada di LAN/Wi-Fi rumah yang sama. Gunakan port bawaan WFAS 9090. Jika memakai kontrol akses, pilih Ask dan izinkan homelab di perangkat pengirim; mode Key belum tersedia di dashboard ini.
